# Instructions

Use this skill when the user wants to check, view, list, or read their upcoming calendar events,
appointments, or schedule for today or a specific timeframe.

## Usage Format

To invoke this skill, respond with exactly:
TRIGGER_CALENDAR_VIEW

## Output Rules

Do not add conversational filler. Output the trigger line and nothing else.

## Example

User: What is my schedule for today?
Agent: TRIGGER_CALENDAR_VIEW
